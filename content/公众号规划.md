# 公众号内容规划

## 一、公众号命名建议

| 候选名 | 定位说明 |
|--------|---------|
| **汇快笔记** | "汇快"呼应 huiquicktool 品牌，"笔记"带个人记录感，工具+分享双重气质 |
| **码上有料** | 谐音"马上有料"，开发者身份（码）+ 内容有干货（料），记忆点强 |
| **小站手记** | "小站"对应个人工具站点，"手记"像个人日记本，亲切不端着 |
| **快工具日记** | 直接点明工具属性，"日记"拉近距离，暗示持续更新 |

> 建议：优先选「汇快笔记」或「码上有料」，前者品牌一致性好，后者传播性更强。

---

## 二、账号定位

一个独立开发者的实战笔记本。分享自己做的实用工具、踩过的开发坑、用过的 AI 好物，偶尔聊聊一个人做产品的日常。不端不装，只说亲测有用的。

## 五、运营建议

### 排版规范

- **字号**：正文15px，标题17-18px，重点加粗
- **行间距**：1.75倍，段落间空一行
- **配色**：正文深灰(#333)，重点用品牌色或蓝色
- **段落**：每段不超过4行，手机一屏3-4段
- **小标题**：用emoji+文字，视觉分区清晰
- **配图**：每300-400字配一张图（截图、流程图、对比图均可）

### 封面图风格

- 统一使用 **2.35:1** 横版封面
- 风格：简洁文字+纯色/渐变背景，不堆元素
- 字体大而醒目，一眼能看懂主题
- 建议配色：深蓝底+白字 / 浅灰底+深色字
- 工具推荐类可加小icon点缀

### 发布时间

- **建议每周三 20:00** 发布
- 理由：周三避开周一忙碌和周五摸鱼，晚8点是阅读高峰
- 提前2小时在微信编辑器排好版，预览确认后再发

### 互动技巧

1. **文末必设互动话题**：问一个具体问题，别问"你有什么想法"这种空话
2. **前10条留言必回**：新号互动率很重要
3. **适时更新头像/简介**：保持和内容调性一致
4. **朋友圈转发**：发布当天转朋友圈，配一句口语化的推荐语
5. **互推合作**：找同量级技术号互推，比单打独斗快
6. **文章末尾统一引导**：

```
觉得有用？点个关注 👇
每周一篇，只说亲测好用的。
公众号：XXX
```
